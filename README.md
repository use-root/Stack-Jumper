### How works

- [x] jump -l _List the directories from chpwd-recent-dirs_
- [x] jump -g (1-9) _Go to the directory that are register_
- [ ] jump -c _Clear all the file_
- [ ] jump -r (1-9) _Remove a directory from the file, with a number_
- [ ] jump -e *Edit the directory *
